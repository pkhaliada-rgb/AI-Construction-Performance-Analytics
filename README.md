# AI Construction Performance, Delay & Cost Prediction System

## Overview

An AI and analytics platform for monitoring residential construction projects, predicting schedule delays and future costs, assessing project risk, analyzing resources, and visualizing project performance geographically.

## Key Features

- Construction performance monitoring
- Delay prediction
- Cost forecasting
- Risk assessment
- Resource analytics
- Schedule and cost performance indicators
- GIS project visualization
- Model comparison and feature importance
- Performance and risk reports

## Workflow

```text
Data Input
   ↓
Data Cleaning & Preprocessing
   ↓
Feature Engineering / Representation
   ↓
Machine Learning / AI Processing
   ↓
Prediction, Classification or Analysis
   ↓
Interactive Dashboard
   ↓
Reports & Decision Support
```

Python, Scikit-learn, Pandas, NumPy, Streamlit, Plotly, GeoPandas, Folium, Joblib

## Running the Project

Install the dependencies:

```bash
pip install -r requirements.txt
```

If model training is included in the project, run the available training script from the `src` directory before launching the dashboard.

To launch the Streamlit application:

```bash
streamlit run app/app.py
```
